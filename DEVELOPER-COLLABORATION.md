# Developer hardware and robotics-software collaboration

**Status: collaboration inquiry only. No sponsorship, equipment, funding, certification or endorsement is claimed.**

Northern Edge Robotics & Fabrication is an Ontario-based, pre-revenue engineering startup developing independent robotics, simulation and GPU software. Our standalone robotics programs are intended for individual technical use and potential optional integration with the **KODIAK KDK-X** wheel-legged humanoid research platform.

## What we are requesting

We would welcome a discussion with Razer's developer-relations, workstation or technical-partnership team—or another appropriate hardware provider—about one or more **no-cost or mutually agreed** opportunities:

- Temporary loan of a suitable workstation or laptop for local graphics, engineering and robotics-software development
- Structured access to a compatible GPU evaluation system or partner testing facility
- Engineering dialogue about developer test workloads and hardware/software compatibility
- A limited, mutually approved nonconfidential evaluation report or co-marketing case study **only if both parties later agree**

This is a request for consideration, **not** a claim that any program supplies free equipment. We cannot commit to a purchase, paid rental or publicity obligation without separately approved terms.

## Proposed evaluation boundaries

1. **Agree scope first:** hardware configuration, access period, test objectives, data handling and responsibility for costs.
2. **Use founder-controlled evaluation:** run a bounded set of legally permitted tests appropriate to the actual device and software maturity.
3. **Report results accurately:** disclose which tests ran, which passed or failed and what limitations remain. Results on one machine are not blanket product certification.
4. **Review any disclosure:** decide separately whether there is value in sharing a short, screened public summary. Publication or co-marketing requires explicit mutual agreement.

Specific algorithms, source, full engineering datasets, sensitive design files, internal architecture and complete qualification evidence **will not be provided through this public repository**. Any deeper access would require separate authorization and suitable confidentiality, IP and usage terms.

## Current context

- Local development: HP OMEN laptop with NVIDIA GTX 1660 Ti
- Selected cloud experimentation: NVIDIA RTX 5090
- Active programs: standalone robotics software, JOTVAR simulation/evaluation, AURYK GPU Runtime, AURYK Studio and KODIAK research
- Commercial stage: pre-revenue; software and integration programs remain at differing development stages

A third party can consider this proposal without inspecting or receiving proprietary project internals.
