# Additional Northern Edge programs

Alongside the featured work, Northern Edge has separate engineering and software programs in several areas. Examples include:

| Program | General area |
| --- | --- |
| NEPP | Physics-related research |
| VectorForge | Engineering and design software |
| Northern Edge Geometry Kernel (NEGK) | Geometry software |
| NE-AUTOMATION-LAB | Automation software |
| NE-MOTION | Robotics motion research |
| NE-PERCEPTION | Robotics perception |
| NE-STATE-ESTIMATION | Sensor fusion and estimation research |
| Northern Edge Real-Time Control Runtime | Real-time robotics software |
| NE-PI | Robotics intelligence research |
| NE-POWERCORE | Power-system engineering |
| Horizon OS | Systems software |
| CORTEX | Software architecture research |

The programs are listed to indicate the **breadth of engineering activity**, not to suggest that every program is a completed or publicly released product. Their technical materials and internal evidence are not included in this showcase.
