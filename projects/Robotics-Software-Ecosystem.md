# Standalone robotics software portfolio

**Nonconfidential program overview — descriptions of engineering work, not a technical implementation guide.**

Northern Edge Robotics & Fabrication is developing multiple independently scoped robotics software programs. The objective is to support individual engineering use cases and, where justified by future verification, allow optional use within the **KODIAK KDK-X** platform.

| Software program | Broad research or development focus |
| --- | --- |
| NE Robot Runtime | Communications, state distribution and runtime coordination |
| Northern Edge Real-Time Control Runtime | Time-sensitive control execution and runtime behaviour |
| NE-STATE-ESTIMATION | Sensor fusion and estimation |
| NE-PERCEPTION | Perception software |
| NE-MOTION | Robotics motion software |
| NE-PI | Robotics intelligence research |
| JOTVAR | Standalone simulation, testing and engineering evaluation |

These labels indicate **distinct program scopes**, not published interfaces, a finished modular product suite or evidence that every integration has been achieved.

## Relationship to KODIAK

KODIAK KDK-X is a **separate wheel-legged humanoid robotics research platform**. It may become a consumer of some independently developed software programs. Neither KODIAK nor any particular simulator, GPU runtime or application is presented as a required dependency for the standalone programs.

Integration maturity, physical hardware state and independent qualification vary. No completed, safe-to-operate humanoid system is asserted here.

## Why developer hardware matters

A suitable local engineering workstation could support repeatable simulation, graphics, desktop testing and controlled software evaluations. A developer partner would receive only a **pre-agreed, nonconfidential** project scope and appropriately screened results.
