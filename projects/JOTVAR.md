# JOTVAR

**Standalone robotics simulation and engineering-evaluation software.**

JOTVAR is developed by Northern Edge for simulation experimentation, repeatable computational testing and desktop engineering workflows.

Its recorded development exercises include local Windows application testing and selected cloud GPU execution on an NVIDIA RTX 5090.
