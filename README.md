# Northern Edge Robotics & Fabrication

**Canadian independent developer of robotics, simulation, GPU and engineering software.**

This repository is a **nonconfidential engineering showcase** for developer-access programs, technical introductions and potential collaborators. It describes selected work at a high level; it is **not** a source-code release, a complete technical architecture, or an offer to license the underlying products.

## Robotics software: standalone first

Northern Edge is developing a **portfolio of distinct robotics software programs**, rather than one inseparable KODIAK software package. Programs address communications/runtime coordination, real-time control, state estimation, perception, motion, robotics intelligence, and simulation/evaluation.

Each is intended to be independently usable within its defined scope. **Optional integration into [KODIAK KDK-X](projects/KODIAK-KDKX.md)** is a development objective, not a mandatory dependency or a claim that complete humanoid integration has been physically validated.

[See the nonconfidential robotics software overview](projects/Robotics-Software-Ecosystem.md).

Access to suitable workstation-class hardware or supervised evaluation systems would support further **developer-controlled** graphics, simulation and robotics software tests.
